# Pose preview avatar

`pose_avatar.vrm` is the sample VRM1 model from the
[@pixiv/three-vrm](https://github.com/pixiv/three-vrm) examples
(`VRM1_Constraint_Twist_Sample.vrm`).

Used only as a lightweight conversation pose/camera preview — not for final
Comfy renders. Replace with your own VRM by overwriting this file or pointing
`createAvatarStage({ modelUrl })` at another URL.
