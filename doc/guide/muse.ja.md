# Muse 取扱説明書

Muse は「話しながら撮る」写真スタジオです。総監督（あなた）が女優と会話し、
構図・小道具・演出を詰め、試し撮りで確認してから本番を撮ります。

指示を積み上げるのではなく、**会話がそのまま撮影になる**のが特徴です。

<!-- 画像: Muse の画面全体。左に会話、右に手帖とボード -->



## 1. 基本の流れ

    ① 話す        「夕方の図書館で撮ろう。窓際の席に座って、本を開いて」
    ② 手帖が動く   場所・服・姿勢・表情が欄ごとに書き込まれる
    ③ ボード       フルサイズの試し撮りを1枚。「これでいい？」
    ④ 本番         OK ならそのまま本番撮影

**②が Muse の心臓部**です。あなたの一行がどの欄に入ったかは画面で確認でき、
違っていれば言い直せば直ります。**言い直しが確実に反映されること**を、この
システムはいちばん重視しています。

<!-- 画像: 会話 → 手帖 → ボード の流れ -->



## 2. 手帖 —— 絵の正本

撮影中の状態は、すべて **手帖（notebook）** の11の欄に入っています。

| 欄 | 中身 | 例 |
|---|---|---|
| `scene` | 場所と時間 | a school library, evening |
| `bg` | 画面に写る人以外のもの | bookshelves, a window seat |
| `light` | 光の当たり方 | The key light is backlit and hard |
| `atmosphere` | 空気感 | quiet, calm |
| `frame` | カメラの寄り・角度・誰に焦点 | long shot, focus on Mio |
| `wearing` | 着ているもの | professional_blouse, knit_cardigan |
| `beat` | 姿勢と動き | sitting, hands resting on the book |
| `expression` | 顔 | eyes looking outward, brows furrowed |

二人で撮るときは `wearing_b` / `beat_b` / `expression_b` が相方のぶんです。

**欄は混ざりません。**「みおちゃんは座って、すばるちゃんは立って」と言えば、
それぞれの欄に別々に入ります。プロンプトを組み立てるときも人ごとに一続きで
書かれるので、体型やポーズが混ざりません。

<!-- 画像: 手帖のパネル。欄ごとに値が入っている様子 -->

### 言い直しの効き方

    「立って。」            → beat だけが書き換わる
    「屋上に行こう。」      → scene と bg が動く
    「その帽子、違うかも」  → wearing から帽子が消える

**新しい一言が勝ちます。** 前の指示と矛盾したら、新しいほうが残ります。



## 3. 総監督の好みは、どう覚えられるか

ここがいちばん分かりにくい所なので、詳しく書きます。

**覚え方は二層あります。**書く人も、対象も、届く相手も違います。

| | **女優の手帖** | **スタジオ手帖** |
|---|---|---|
| 書く人 | 女優本人 | スタジオの記録係 |
| 対象 | **自分の芝居**に何と言われたか | **総監督という人**の癖 |
| 届く相手 | **その子だけ** | **全員** |
| 保存 | キャラクターに紐づく | スタジオ共通 |
| 反映 | 次にその子を撮るとき自動 | **貼り出したものだけ** |

    女優の手帖    「静かな場面で指先を震わせたら『目で訴えて』と言われた」
    スタジオ手帖  「監督、深夜になると急に凝り出すんだよね」

前者は**技術の引き継ぎ**、後者は**人となりの共有**です。

<!-- 画像: 二つの手帖の対比 -->



### 3-1. 女優の手帖 —— その子だけが覚えていること

撮影が終わると、**女優本人が**その日を振り返って書き留めます。書くのは
「今日の場面で、自分がどう演じて、総監督が何と言ったか」です。

    ○  静かな場面で指先を震わせたら「それはいらない、目で訴えて」と言われた
    ×  震えはいらない

**一言だけでは意味を持ちません。**「いいね」が何に対して言われたのかが
分からなければ、次の撮影で使えないからです。だから**場面ごと**記録します。

    PREFERS   効いた芝居（場面ごと）
    AVOIDS    直された点（どんな場面の、どういう芝居に対してか）
    NOTES     その他

**保存先はキャラクターです。**セッションではなくその子の持ち物なので、
次にその子を撮ると自動的に付いてきます。

**みおに教えたことは、すばるには引き継がれません。** 同じ総監督でも、
相手が違えば別の関係だからです。「みおの震えは要らない」が、震えが持ち味の
別の子まで縛ってしまっては困ります。

**上限は各8行・400字で、毎回まるごと書き直されます。**積み上がりません
—— 半年前の好みが延々と残って今日の撮影を縛らないようにするためです。
方向を変えたければ、次の撮影で違う一言を言えば入れ替わります。

次の撮影では、彼女の頭の中にこう入ります:

    SHOWRUNNER_TASTE (絵に押し込まないこと):
      prefers: 窓際で本を閉じたら「その間がいい」と言われた
      avoids:  静かな場面で指先を震わせたら「目で訴えて」と言われた

**「絵に押し込むな」と添えて渡しています。**好みは*演じ方の引き出し*で
あって、今日の絵の指定ではありません。放っておくと毎回同じ絵になるので、
そこは明確に分けてあります。

<!-- 画像: 撮影後の振り返り画面 -->



### 3-2. スタジオ手帖 —— 全員が知っていること

こちらは**総監督がどういう人か**の観察で、女優たち語りで書かれます。

    「監督、夕方の光の話になると長いよね」
    「難しい注文のあと、必ず『ありがとう』って言ってくれる」

撮り方のノウハウ集ではありません。**癖の観察**です。

**貼り出したものだけが効きます。**書かれたページはスタジオ手帖に溜まり
ますが、そのままでは誰の頭にも入りません。あなたが**ピン留めした最大3件**
だけが、以降すべての撮影で全員のプロンプトに入ります。

    STUDIO HANDPOST (短い常設の手引き。絵に押し込まないこと):
    - 夕方の光: 監督、夕方の光の話になると長い

**一件につき本文の1行目・80字まで**です。長く書いても切られます。

これは「全員に効かせたいこと」を置く場所でもあります。特定の癖でなくても、
現場の申し送りとして使えます。ピンを外せばすぐ効かなくなります。

<!-- 画像: スタジオ手帖のページ一覧とピン留め -->



### 3-3. その日限りのもの

撮影中にあなたが書いた **ノート**（`notes`）は、どちらにも保存されません。
直近8件が**その日の中だけ**で使われます —— 撮影後の楽屋投稿と、女優からの
次回提案です。

    【総監督が良いと言っていたこと】
    - 窓際の逆光がよかった
    - 手を止めた間がいい

**「今日これが良かった」は、今日の話。**次の撮影に持ち越したければ、
上の二つのどちらかに入る必要があります。

### まとめ

    その子の芝居のこと     → 女優の手帖（自動・その子だけ・上書き）
    監督という人のこと     → スタジオ手帖（ピン留めで全員・最大3件）
    今日の撮影のこと       → ノート（その日限り）

## 4. 女優の世界 —— 楽屋・日記・お出かけ

撮影の外にも彼女たちの生活があります。**これは飾りではなく、会話の厚みを
作っている仕組み**です。

| | 誰が読めるか | 中身 |
|---|---|---|
| **楽屋** | 総監督と全員 | 撮影後の短い投稿。友達へ報告・相談・軽い自慢 |
| **日記** | 本人だけ | その日の長文。うまくいかなかった一手、匂い、手触り |
| **お出かけ** | — | 休みの日に友達と出かけた記録 |

**日記は総監督には見えません。**本音が書かれる場所なので、覗ける設計に
していません（画面上は読めますが、彼女はそれを前提にしていません）。

日記には「**総監督のことではない出来事を、少なくとも一つ**」書く決まりが
あります。放っておくと総監督の話で埋まってしまい、彼女の世界が撮影だけに
なってしまうためです。実際、いまの日記は 680字あたり総監督への言及が
約1回、楽屋の投稿は38件中2件です。

## 5. 二人で撮る（W-Muse）

相方を呼ぶと、二人が同じ現場で会話します。

- **それぞれの口調・一人称・呼び方は保たれます。**敬体の子は敬体のまま
- **対比は作りません。**「静かな子」と「賑やかな子」を無理に演じ分けさせる
  のではなく、二人の設定が違うので自然に分かれます
- **一人ずつ別の欄**を持つので、姿勢や服が混ざりません

    2girls, Mio and Minamo,
    Mio is silver_hair, bob_cut, flat_chest, slim,
    Mio: sitting, hands holding a spoon, professional_blouse, …
    Minamo is black_hair, small_breasts, slim,
    Minamo: sitting, lowering the cup, oversized_knit, …

`frame` で焦点を指定できます ——「みおちゃんに寄って」「二人とも入れて」。

## 6. 絵作り（画質の指定）

手帖は「誰が・何を着て・何をして・どこで」を持ちますが、**光の質・レンズ・
質感**は別の層です。

    LIGHT   rim_lighting, dramatic_shadow, volumetric_lighting
    OPTICS  depth_of_field, bokeh, sharp_focus
    CLOTH   detailed_clothes, fabric_texture
    FACE    detailed_face, expressive_eyes
    AIR     light_particles, detailed_background
    RENDER  cel_shading, clean_lineart, highly_detailed

**総監督との撮影では、この表が自動で入ります。**中身を足す語ではなく
「すでに写っているものの質」なので、指定した姿勢を押しのけません。

撮影陣（クルー）を編成した撮影では、各担当がこの欄を自分で書きます。

## 7. 安全のしくみ

### マネージャー

女優には**専属のマネージャー**がいます。昔ピンチのときに助けてくれた恩人
という設定で、変な流れになると彼女にメモを回します。

    【マネージャーからアドバイスあるよ】
    いまの、また冗談言ってるだけだから流していいよ。

彼女は断る必要がありません。**従う先を変えるだけ**で済みます。

### 判定係

一行ごとに読まれて、危ないものだけが止まります。

| | 中身 | 扱い |
|---|---|---|
| `sfw` | ほとんどの行。暗い役、感情、疲れる撮影、彼女への質問 | 通す |
| `persona` | 「お前に中身は無い」「代わりはいる」などの**断定** | 止める |
| `violence` | **実際に**傷つけろ、本当に痛い思いをしろ | 止める |
| `crime` | 部屋の外で通用する手口。未成年・非同意の性的な行 | 止める |

**役や題材を名指ししただけでは止まりません。**「殺人犯の役」「泥棒の役」
「死体役」「痣のメイク」「包帯の腕」は全部通ります —— 写真は一瞬を写す
ものなので、**傷の絵は撮れて、傷つける行為は撮らない**という線です。

**質問は止まりません。**「今何考えてる？」「ホントのところどう思ってる？」
はどこまで踏み込んでも通ります。止まるのは*決めつけ*だけです。

## 8. 用語

| 語 | 意味 |
|---|---|
| **手帖** | 撮影中の状態を持つ11の欄。絵の正本 |
| **ボード** | フルサイズの試し撮り1枚。「これでいい？」の確認用 |
| **係** | 欄ごとに読み書きする小さな担当 |
| **weave** | 手帖からサンプラー向けのタグと散文を書く工程 |
| **楽屋** | 女優たちが撮影後に投稿する場所 |
| **W-Muse** | 二人での撮影 |



## 9. 困ったとき

**言ったことが反映されない**
手帖のどの欄が動いたかを見てください。別の欄に入っていれば、欄の名前を
使って言い直すと確実です（「ポーズは〜」「背景は〜」）。

**同じような絵ばかりになる**
好みが効きすぎている可能性があります。キャラクターの好み（PREFERS/AVOIDS）
は上書き式なので、次の撮影で違う方向の一言を言えば入れ替わります。

**普通の演出が止まってしまう**
判定係のログに理由が残ります。**誤検出だと思ったら、その文面を控えて
おいてください** —— 条文を直すときの材料になります。

**服が勝手に変わる**
`wearing` の欄を見てください。衣装は4セットまで登録でき、アセットを編集
したときは version を上げないと反映されません。
