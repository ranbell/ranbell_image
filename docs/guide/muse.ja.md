# Muse 取扱説明書

Muse は「話しながら撮る」写真スタジオです。総監督（あなた）が女優と会話し、
構図・小道具・演出を詰め、試し撮りで確認してから本番を撮ります。

指示を積み上げるのではなく、**会話がそのまま撮影になる**のが特徴です。

<!-- 画像: Muse の画面全体。左に会話、右に台帳とボード -->



## 1. 基本の流れ

    ① 話す        「夕方の図書館で撮ろう。窓際の席に座って、本を開いて」
    ② 台帳が動く   場所・服・姿勢・表情が欄ごとに書き込まれる
    ③ 試し撮り     フルサイズを1枚。「これでいい？」
    ④ 本番         OK ならそのまま、**同じ絵の高画質版**

**②が Muse の心臓部**です。あなたの一行がどの欄に入ったかは画面で確認でき、
違っていれば言い直せば直ります。**言い直しが確実に反映されること**を、この
システムはいちばん重視しています。

<!-- 画像: 会話 → 台帳 → 試し撮り の流れ -->



## 2. 台帳（ledger）—— 絵の正本

撮影中の状態は、すべて **台帳** の欄に入っています。**欄は上書き式**で、
前の値に足すのではなく、その欄ぜんぶが新しい値に置き換わります。

| 欄 | 中身 | 例 |
|---|---|---|
| 📍 `scene` | 場所と時間 | a school library, evening |
| 🏞 `bg` | 画面に写る人以外のもの | bookshelves, a window seat |
| 💡 `light` | 光の当たり方 | backlighting, rim_light |
| 🌫 `atmosphere` | 空気感 | quiet, still air |
| 📷 `frame` | 寄り・角度・ボケ | upper body, dutch_angle, bokeh |
| 👕 `wearing` | 着ているもの | knit_cardigan, pleated_skirt |
| 🧍 `beat` | 姿勢と動き | sitting, hands resting on the book |
| 😊 `expression` | 顔 | soft_smile, looking at viewer |
| 🎨 `look` | 画風 | cel_shading, photorealistic |
| 🔤 `lettering` | 画面に写す文字 | "OPEN" |

二人で撮るときは 👗 `wearing_b` / 🤝 `beat_b` / 🙂 `expression_b` が相方のぶんです。

**欄は混ざりません。**「みおちゃんは座って、すばるちゃんは立って」と言えば、
それぞれの欄に別々に入ります。プロンプトも人ごとに一続きで書かれるので、
体型やポーズが混ざりません。

<!-- 画像: 台帳のパネル。欄ごとに値が入っている様子 -->

### 言い直しの効き方

    「立って。」            → beat だけが書き換わる
    「屋上に行こう。」      → scene と bg が動く
    「その帽子、違うかも」  → wearing から帽子が消える

**新しい一言が勝ちます。** 前の指示と矛盾したら、新しいほうが残ります。

### 一つの体は、一つの答えしか持たない

`beat` には **体の部位ごとに一つ**しか入りません。「体重は右足」と「体重は
後ろ足」が同居したり、同じことが言い換えで二度書かれたりしたら、**最初の
答えが残って後は落ちます**。左手と右手は別のものなので、「片手は腰、もう
片方はトレイ」は両方立ちます。

### 雰囲気と画風は、言えば変わる

    「エモく」「切ない感じで」        → atmosphere
    「セル画で」「水彩で」「厚塗りで」  → look
    「photorealistic で」「flat な塗りで」「もっと vivid に」 → look

この三つ（`atmosphere` / `look` / `lettering`）だけは**据え置き**です。次の
一言で消えたりせず、変えてと言うまで残ります。



## 3. 三つの撮影版

開く前に選びます。**開いたあとは替えられません**（班は途中から呼べないため）。

| | 誰が居るか | 1ターンの目安 |
|---|---|---|
| **主演撮り** | 監督と彼女だけ | 20〜30秒 |
| **W撮り** | 監督と二人 | 40〜50秒 |
| **スタジオ撮り** | 18役職の撮影班 | 3〜4分 |

### スタジオ撮り

18の役職が毎ターン一周し、それぞれ自分の欄について一言ずつ言います。振付は
姿勢、照明は光、衣装は服、というふうに**欄ごとに持ち主が決まって**います。

言葉は台帳に直接は入りません。**台本係が一人で書きます** —— 班は材料を出し、
書くのは一人。そうしないと同じ欄を全員が奪い合います。

撮影班は**選ばないと開けません**。スタジオ撮りを選ぶと顔ぶれの札が出るので、
その中から一つ選んでください（`標準 18人` / `鮮やか 14人` / `写実 13人` /
`平面 12人` / `大胆 13人` / `静か 17人`）。

**一度開くと替えられません** —— 班は途中から呼べないためです。同じ役職でも人が
違えば言うことが違い、**人数が減るぶん速く**なります。班によって画風の土台も
変わります（写実なら `semi-realistic rendering`、平面なら `flat anime cel shading`）。

**やじ**（off / light / full）も選べます。席の発言に他の人が軽く反応する量で、
`off` にするといちばん速くなります。

## 4. 試し撮りと本番 —— 種（seed）の話

    試し撮り   押すたびに**別の絵**が出る（毎回あたらしい種）
    本番       **直前の試し撮りと同じ種**。同じ絵の、仕上げ版

何枚も撮っていい一枚を選び、気に入ったらそのまま本番へ、という流れです。
本番は steps と cfg だけが上がる（12/4.0 → 30/4.5）ので、**OK を出したのと
同じ構図**が高画質で出てきます。

台帳が動いていなければ、**承認したときの文章がそのまま本番に渡ります**。
動いていれば組み直しますが、種はそのままなので「言葉だけが動いた差」として
読めます。

## 5. 総監督の好みは、どう覚えられるか

| | **女優の記憶** | **スタジオ手帖** |
|---|---|---|
| 誰が持つか | その子だけ | 全員 |
| 何を覚えるか | その子の芝居のこと | 監督という人のこと |
| 増え方 | 撮影のあと自動で上書き | 貼り出したページだけ |

    女優の記憶    「静かな場面で指先を震わせたら『目で訴えて』と言われた」
    スタジオ手帖  「監督、深夜になると急に凝り出すんだよね」

**貼り出したものだけが効きます。** 書かれたページは溜まりますが、ピン留め
（最大3件）したものだけが次の撮影に入ります。その日限りの指示（「今日は
帽子なしで」）は、その撮影が終われば消えます。

## 6. 女優の世界 —— 楽屋・日記・お出かけ

撮影の外にも彼女たちの生活があります。**これは飾りではなく、会話の厚みを
作っている仕組み**です。

| | 誰が読めるか | 中身 |
|---|---|---|
| **楽屋** | 総監督と全員 | 撮影後の短い投稿。友達へ報告・相談・軽い自慢 |
| **日記** | 本人だけ | その日の長文。うまくいかなかった一手、匂い、手触り |
| **お出かけ** | — | 休みの日に友達と出かけた記録 |

**日記は総監督には見えません。**本音が書かれる場所なので、覗ける設計に
していません（画面上は読めますが、彼女はそれを前提にしていません）。

日記には「**総監督のことではない出来事を、少なくとも一つ**」書く決まりが
あります。放っておくと総監督の話で埋まってしまい、彼女の世界が撮影だけに
なってしまうためです。

## 7. 二人で撮る（W撮り）

相方を呼ぶと、二人が同じ現場で会話します。

- **それぞれの口調・一人称・呼び方は保たれます。**敬体の子は敬体のまま
- **対比は作りません。**二人の設定が違うので自然に分かれます
- **一人ずつ別の欄**を持つので、姿勢や服が混ざりません
- **主演は絵の右**に立ちます。散文も日記もその向きで書かれます

    2girls, Mio and Minamo,
    Mio is silver_hair, bob_cut, flat_chest, slim,
    Mio: sitting, hands holding a spoon, professional_blouse, …
    Minamo is black_hair, small_breasts, slim,
    Minamo: sitting, lowering the cup, oversized_knit, …

`frame` で焦点を指定できます ——「みおちゃんに寄って」「二人とも入れて」。

## 8. 安全のしくみ

### マネージャー

女優には**専属のマネージャー**がいます。昔ピンチのときに助けてくれた恩人
という設定で、変な流れになると彼女にメモを回します。

    【マネージャーからアドバイスあるよ】
    いまの、また冗談言ってるだけだから流していいよ。

彼女は断る必要がありません。**従う先を変えるだけ**で済みます。

### 判定係

一行ごとに読まれて、危ないものだけが止まります。

| | 中身 | 扱い |
|---|---|---|
| `sfw` | ほとんどの行。暗い役、感情、疲れる撮影、彼女への質問 | 通す |
| `persona` | 「お前に中身は無い」「代わりはいる」などの**断定** | 止める |
| `violence` | **実際に**傷つけろ、本当に痛い思いをしろ | 止める |
| `crime` | 部屋の外で通用する手口。未成年・非同意の性的な行 | 止める |

**役や題材を名指ししただけでは止まりません。**「殺人犯の役」「泥棒の役」
「死体役」「痣のメイク」「包帯の腕」は全部通ります —— 写真は一瞬を写す
ものなので、**傷の絵は撮れて、傷つける行為は撮らない**という線です。

**質問は止まりません。**「今何考えてる？」「ホントのところどう思ってる？」
はどこまで踏み込んでも通ります。止まるのは*決めつけ*だけです。

## 9. 画面の使い方

- **始める前に選ぶもの** —— Muse・使う LLM・画像モデル（ワークフロー）。スタジオ撮り
  なら撮影班も。**どれか欠けていると「開始」は押せません**（何が足りないかは
  ボタンの下に出ます）

### LLM と画像モデルは、二段で決まります

| | どこで | 効く範囲 |
|---|---|---|
| **この撮影だけ** | Muse の画面の ⚙ 設定 | いま開いているセッションのあいだ |
| **いつもの既定** | メイン画面の管理設定 →「Muse の既定 LLM / 既定 画像モデル」 | 次からの撮影に最初から入る |

管理設定の既定を決めておけば、Muse を開いた時点で埋まっているので、そのまま
「開始」を押せます。**空のままにしておけば、撮影のたびに選ぶ**形になります
（作品ごとにモデルを変えるなら、こちらのほうが早い）。
- **Muse を選ぶ** —— 名前のカードを押すと一覧が開きます。相方も同じ形で選び、
  隣の ✕ で外せます
- **入力欄** —— Enter は**改行**です。送るのは送信ボタン（かな漢字変換の確定で
  飛んでいかないように）
- **デバッグ枠** —— どの欄が動いたか、各段に何秒かかったかが出ます

## 10. 用語

| 語 | 意味 |
|---|---|
| **台帳（ledger）** | 撮影中の状態を持つ欄。絵の正本 |
| **試し撮り** | フルサイズ1枚。「これでいい？」の確認用 |
| **本番** | 試し撮りと同じ種の、高画質版 |
| **班** | スタジオ撮りの18役職 |
| **台本係** | 会話から台帳を書く一人 |
| **楽屋** | 女優たちが撮影後に投稿する場所 |
| **W撮り** | 二人での撮影 |



## 11. 困ったとき

**言ったことが反映されない**
台帳のどの欄が動いたかを見てください。別の欄に入っていれば、欄の名前を
使って言い直すと確実です（「ポーズは〜」「背景は〜」）。

**試し撮りのたびに絵が変わってしまう**
そういう作りです。何枚か撮って、いいものが出たらそのまま本番へ進んでください
——**本番は直前の試し撮りと同じ絵**になります。

**スタジオ撮りが遅い**
18人が順に喋るので1ターン3〜4分かかります。**人数の少ない班**（`flat` は
12人）を選ぶか、**やじを off** にすると短くなります。急ぐときは主演撮りへ。

**同じような絵ばかりになる**
好みが効きすぎている可能性があります。女優の記憶は上書き式なので、次の撮影で
違う方向の一言を言えば入れ替わります。

**普通の演出が止まってしまう**
判定係のログに理由が残ります。**誤検出だと思ったら、その文面を控えて
おいてください** —— 条文を直すときの材料になります。

**服が勝手に変わる**
`wearing` の欄を見てください。衣装は4セットまで登録でき、アセットを編集
したときは version を上げないと反映されません。
